第一部：認識架構

先花五分鐘看懂它怎麼運作，後面每個安裝步驟你都會知道自己在裝什麼。

一般聊天機器人需要一台 24 小時開機的伺服器待命。meltan-404-bot 改用兩個免費雲端服務拼起來：Cloudflare Worker 當接線生，GitHub Actions 當臨時工。接線生全年無休但只做轉接；臨時工收到工作才上工，做完就下班。兩邊都在免費額度內，所以伺服器費用是 0 元。

第二部：安裝

照順序做完九個步驟。每一步結尾有「完成確認」清單，打勾了再往下走。

開始之前你需要一台 macOS、Linux 或 Windows 電腦，和一個能收簡訊或 Email 的手機（註冊帳號用）。所有指令都是複製貼上，不需要會寫程式。
1

約 20 分鐘，全部免費申請

下面是需要的帳號。Telegram 你可能已經有了；HuggingFace 和 Tavily 是選用，跳過的話對應功能不能用，其他功能不受影響。

帳號去哪申請用途費用
Telegram手機安裝 Telegram App聊天介面免費
GitHubgithub.com/signup放程式碼、跑 Actions、Copilot帳號免費
GitHub Copilotgithub.com/features/copilot機器人的大腦Free 方案有每月額度，Pro 每月 10 美元
Cloudflaredash.cloudflare.com/sign-up跑 Worker 接線生免費方案即可，不用綁信用卡
HuggingFace（選用）huggingface.co/join/draw 畫圖有免費額度，超過按量計費
Tavily（選用）app.tavily.com/research 搜尋有免費額度

完成確認
  • 手機能開啟 Telegram
  • 能登入 GitHub，且 Copilot 已啟用（Free 或 Pro）
  • 能登入 Cloudflare Dashboard
2

建立 Telegram Bot

約 5 分鐘，在手機或電腦的 Telegram 完成

Telegram 的機器人是向官方機器人 @BotFather 申請的：

  1. 在 Telegram 搜尋 @BotFather（認明藍勾勾），開始對話。
  2. 送出 /newbot。
  3. 它會問機器人的顯示名稱，隨意取，例如 My Meltan Bot。
  4. 再問帳號名稱，必須以 bot 結尾且全網不重複，例如 my_meltan_404_bot。
  5. 成功後 BotFather 會給你一串 Bot Token，長得像 1234567890:AAHxxx...。複製存好，安裝腳本會用到。

接著查你自己的 Telegram User ID（數字），機器人只回覆白名單上的人：

  1. 在 Telegram 搜尋 @userinfobot，開始對話。
  2. 它會回覆你的 Id，是一串數字，複製存好。
Bot Token 等於機器人的鑰匙拿到 Token 的人就能控制你的機器人。不要貼到公開的地方；如果外流，回 BotFather 用 /revoke 換一把新的。
完成確認
  • 手上有一串 Bot Token
  • 手上有自己的 User ID 數字
3

Fork 專案到自己帳號

約 5 分鐘，在瀏覽器完成

Fork 的意思是把這份程式碼複製一份到你自己的 GitHub 帳號底下，機器人會跑在你的副本上：

  1. 打開 github.com/yazelin/meltan-404-bot，點右上角的 Fork，再點 Create fork。
  2. 完成後網址會變成 github.com/你的帳號/meltan-404-bot，之後的操作都在這個副本上。
  3. 到副本的 Actions 分頁。GitHub 預設會停用 fork 來的自動化流程，看到綠色按鈕 I understand my workflows, go ahead and enable them 就點下去。
這一步最常被漏掉沒有啟用 Actions，機器人就永遠不會動工。之後如果發現訊息毫無反應，先回來檢查這裡。
完成確認
  • 自己帳號底下有 meltan-404-bot 這個 repo
  • Actions 分頁已啟用，看得到 Telegram Chatbot 和 Deploy Dashboard 兩個 workflow

安裝命令列工具

約 15 分鐘，依你的作業系統擇一

安裝腳本需要這些工具：git、gh（GitHub 官方指令）、Node.js 20 以上、wrangler（Cloudflare 官方指令）、python3、openssl、curl。照你的系統做：

macOS

打開「終端機」App，先裝 Homebrew（如果還沒有），然後：

brew install git gh node python3
npm install -g wrangler

Windows

安裝腳本是 bash 寫的，建議透過 WSL（Windows 內建的 Linux 環境）執行。以系統管理員開啟 PowerShell:

wsl --install

重開機、設定好 Ubuntu 的使用者密碼後，打開 Ubuntu 視窗，改照下面的 Ubuntu 步驟做。

Ubuntu/Debian（含 WSL）

# 基本工具
sudo apt update
sudo apt install -y git gh curl python3 openssl

# Node.js 20:用 nvm 安裝(apt 內建版本太舊)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.bashrc
nvm install 20

# Cloudflare 的指令工具
npm install -g wrangler

最後確認版本，每一行都要有回應而不是 command not found:

git --version && gh --version && node --version && wrangler --version && python3 --version
完成確認
  • 上面的版本確認指令每項都印出版本號
  • node --version 是 v20 以上
5

登入 GitHub 與 Cloudflare

約 10 分鐘

先讓 gh 登入你的 GitHub 帳號。跑下面的指令，依提示選 GitHub.com、HTTPS、Login with a web browser，把畫面上的一次性代碼貼到瀏覽器：

gh auth login

再讓 wrangler 登入 Cloudflare，會自動開瀏覽器要你按 Allow:

wrangler login
WSL 使用者如果瀏覽器沒有自動打開，把終端機印出的網址手動複製到 Windows 的瀏覽器開啟即可。

然後把你 fork 的副本下載到電腦（記得把「你的帳號」換成 GitHub 帳號名）：

gh repo clone 你的帳號/meltan-404-bot
cd meltan-404-bot
完成確認
  • gh auth status 顯示 Logged in
  • wrangler whoami 顯示你的 Cloudflare 帳號
  • 電腦裡有 meltan-404-bot 資料夾，而且已經 cd 進去
6

準備金鑰

約 10 分鐘，把每一把金鑰存進記事本備用

安裝腳本會依序問你四把金鑰。先準備好，到時候直接貼：

A. Telegram Bot Token（必要）

步驟 2 從 BotFather 拿到的那串。

B. GitHub PAT（可直接跳過）

Worker 需要一把 GitHub 鑰匙才能觸發 Actions。腳本問到這題時直接按 Enter 跳過，它會自動用你剛登入的 gh 帳號授權，最簡單。想收窄權限的進階使用者，可以到 GitHub 的 Settings、Developer settings、Fine-grained tokens 建一把只授權這個 repo 的 token，權限給 Actions（Read and write）和 Contents(Read-only)。

C. Copilot Token（必要）

臨時工上工時要代表你使用 Copilot。用同一個已開通 Copilot 的帳號執行：

gh auth token

印出來的那串就是，複製備用。

D. HuggingFace Token（選用，/draw 畫圖用）

登入 HuggingFace 後到 Settings 的 Access Tokens，按 Create new token，類型選 Read，建立後複製 hf_ 開頭的字串。跳過則 /draw 不能用。

E. Tavily API Key（選用，/research 用）

登入 app.tavily.com，首頁就能複製 tvly- 開頭的 API Key。跳過則 /research 和 YouTube 替代搜尋不能用。

完成確認
  • 記事本裡有：Bot Token、Copilot Token
  • 要用畫圖的話，有 hf_ 開頭的 Token
  • 要用研究的話，有 tvly- 開頭的 Key
7

執行安裝腳本

約 10 分鐘，大部分時間在等它跑

在 meltan-404-bot 資料夾裡執行：

bash setup.sh

它會依序問你：

  1. Telegram Bot Token：貼上金鑰 A。
  2. Telegram User ID：貼上步驟 2 查到的數字，這就是白名單。
  3. GitHub PAT：直接按 Enter（用 gh 的授權）。
  4. HuggingFace Token：貼上金鑰 D，沒有就按 Enter。
  5. Tavily API Key：貼上金鑰 E，沒有就按 Enter。
  6. Copilot GitHub Token：貼上金鑰 C。

之後它會自動完成所有接線：建立 KV 資料庫、部署 Worker 到 Cloudflare、把金鑰分別存進 Cloudflare 和 GitHub 的保險箱（secrets）、向 Telegram 登記 Webhook。最後看到 Setup Complete! 和你的 Worker 網址就是成功了，把網址記下來，步驟 9 會用到。

完成確認
  • 畫面出現 Setup Complete!
  • 記下了 https://meltan-404-relay.xxx.workers.dev 這樣的 Worker 網址
  • Webhook registered successfully 有出現

測試機器人

約 5 分鐘

回到 Telegram，打開你在步驟 2 建立的機器人（搜尋它的帳號名），依序測試：

  1. 送 /models：應該幾秒內回覆可用的畫圖模型清單。這一層由 Worker 直接處理，能回就代表 Webhook 通了。
  2. 隨便聊一句，例如「自我介紹一下」：第一次會等 1 到 2 分鐘，因為臨時工要開機、裝環境。這能回就代表 Actions 和 Copilot 都通了。
  3. 有設 HuggingFace 的話送 /draw 一隻太空貓。

想看幕後過程，打開你 fork 副本的 Actions 分頁，每則訊息都是一次 Telegram Chatbot 的執行紀錄，點進去能看到每一步在做什麼。

完成確認
  • /models 有回覆
  • 一般聊天有回覆

啟用 Dashboard

約 5 分鐘，選用但推薦

Dashboard 是統計與對話紀錄的網頁，放在 GitHub Pages（免費的靜態網頁空間）:

  1. 到你 fork 副本的 Settings，左邊選 Pages。
  2. Build and deployment 的 Source 選 GitHub Actions。
  3. 到 Actions 分頁，左邊選 Deploy Dashboard，按右邊的 Run workflow。
  4. 跑完後網站會出現在 https://你的帳號.github.io/meltan-404-bot/。
  5. 打開網站，點右上角齒輪，填入步驟 7 記下的 Worker 網址和你的 User ID（私聊時 Chat ID 就是你的 User ID），存檔。
完成確認
  • Dashboard 網址打得開
  • 統計卡片有數字，聊天紀錄看得到剛才的測試對話

疑難排解

依「訊息走到哪裡斷掉」來排查，和架構圖的順序一樣。

送 /models 沒反應

訊息還沒走到 Worker。依序檢查：

  • 重跑一次 Webhook 登記：瀏覽器打開 你的Worker網址/register?token=你的TELEGRAM_SECRET。TELEGRAM_SECRET 在 setup.sh 執行時自動產生；最簡單的做法是重跑一次 bash setup.sh，它會重新登記。
  • 確認你傳訊息的帳號就是白名單上的 User ID。改白名單：編輯 worker/wrangler.toml 的 ALLOWED_USERS（多人用逗號分隔），然後 wrangler deploy --cwd worker 重新部署。

/models 會回，但聊天永遠沒下文

Worker 正常，是臨時工沒上工或倒在半路：

  • fork 副本的 Actions 分頁是否已啟用（步驟 3 的綠色按鈕）。
  • Actions 分頁完全沒有新的執行紀錄：Worker 的 GitHub 鑰匙沒生效，重跑 bash setup.sh。
  • 有執行紀錄但是紅色叉叉：點進去看是哪一步失敗。常見是 Copilot Token 無效或該帳號沒開通 Copilot（金鑰 C 重拿一次），或 Copilot 額度用完。

/draw 回錯誤

  • HF Token 沒設或打錯：重跑 bash setup.sh 補上。
  • HuggingFace 免費額度用完：到 HuggingFace 帳號的 billing 頁面確認。

/download 下載 YouTube 失敗

YouTube 會封鎖資料中心的 IP，這是正常的。機器人會自動搜尋 Bilibili、Dailymotion 等替代來源；如果仍然需要直接下載 YouTube，在電腦上執行 bash update-cookies.sh，它會把你瀏覽器的 YouTube cookies 上傳到 GitHub secrets 給臨時工使用。

Dashboard 一片空白或讀不到資料

  • 齒輪設定裡的 Worker 網址要含 https:// 開頭、結尾不要斜線。
  • Chat ID 填錯：私聊時就是你的 User ID 數字。
  • 先傳幾則訊息給機器人，KV 裡有資料 Dashboard 才有東西可顯示。

費用與安全

裝完之後，這兩件事值得知道。

錢會花在哪裡

項目免費額度什麼情況要付錢
Cloudflare Worker+KV免費方案每天十萬次請求等級的額度個人聊天用量幾乎不可能超過
GitHub Actions公開 repo 免費把 repo 改成私有才會開始算分鐘數
GitHub CopilotFree 方案每月有限額重度使用建議 Pro，每月 10 美元
HuggingFace每月有免費推論額度畫圖量大時按量計費，每張約 0.001 美元
Tavily每月有免費額度研究量大時需付費方案

安全注意

  • 白名單是你的荷包保險：機器人只回應 ALLOWED_USERS 裡的 User ID。不要設成空的，否則任何找到你機器人的人都能消耗你的 Copilot 額度。
  • 金鑰不要進到程式碼裡:setup.sh 已經把所有金鑰放進 Cloudflare 和 GitHub 的 secrets 保險箱，不會出現在 repo 檔案中。自己改程式時也維持這個原則。
  • token 外流的處理:Telegram Token 用 BotFather 的 /revoke 重發；GitHub token 到 Settings 撤銷；然後重跑 bash setup.sh。

裝好了嗎？回 Telegram 跟你的機器人說聲嗨。改造它的第一站是 prompt.md，那是機器人的個性與行為說明書，改完 push 上去，下一則訊息就會生效。
